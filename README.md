# SkillBox

A VSCode extension for managing Agent Skills from subscription sources.

## Usage

### 1. Add a Subscription Source

Click the **+** icon in the SkillBox panel and enter a GitHub URL or local path.

### 2. Browse and Install

Expand a source to see available skills, then right-click to install.

### 3. Manage Sources

Right-click a source to sync, open, or remove it.

## Configuration

Click the **gear** icon in the panel or search "skillbox" in VSCode settings.

- **Default Agent** — Target agent for skill installation (Copilot, Claude, Cursor, etc.)
- **Central Repository** — Local storage path for synced skills (default: `~/.skillbox`)
