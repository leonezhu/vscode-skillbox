# SkillBox 📦

VSCode extension for managing Agent Skills from subscription sources.

## Features

- 📥 Subscribe to skill repositories (GitHub or local)
- 🔄 Sync skills from sources
- 📦 Install skills to your project
- ⚙️ Support multiple agents (Copilot, OpenClaw, Claude)

## Usage

1. Open SkillBox panel from the activity bar
2. Click "+" to add a subscription source
3. Expand a source to see available skills
4. Click "Install" to add a skill to your project

## Configuration

- `skillbox.centralRepo`: Central repository path for storing synced skills
- `skillbox.defaultAgent`: Default agent type (copilot, openclaw, claude)
- `skillbox.defaultScope`: Default installation scope (project, global)
